# 12 社区用语

关键词：FF14 黑话、简称、国服招募、队伍位置、高难术语、BZY、紧急遭遇战、萌新。

本词表用于理解群聊和招募，不代表统一官方定义。简称会随版本、服务器和固定队习惯变化；特别是机制简称和攻略站位，先看队伍宏或招募说明，有歧义就问清楚。

## 职责与队伍位置

- **T / 坦**：坦克职业，主要负责承受首领攻击和维持敌人仇恨。
- **H / 奶**：治疗职业，负责恢复队伍生命值并提供辅助。
- **D / DPS / 输出**：以造成伤害为主的职业。
- **MT / ST**：主坦 / 副坦，是八人队伍中常见的职责分工。具体谁负责拉怪、换坦或接特定机制，按该副本情况和队伍安排。
- **H1 / H2**：攻略或队伍宏中标记的治疗站位。
- **D1 / D2 / D3 / D4**：攻略或队伍宏中标记的输出站位。通常是八人机制分位，不是固定职业名称。
- **LB**：极限技（Limit Break）。使用时机一般由队伍协商，某些副本有特定处理方式。
- **AOE**：范围攻击或范围效果。看见提示时要结合地面范围、读条和副本机制判断。
- **GCD / oGCD**：公共复唱技能 / 独立复唱能力。常用于讨论技能循环和爆发安排。

## 副本难度与队伍目标

- **极 / 极神**：极难度讨伐或歼灭战。
- **零式**：高难度团队副本，英文常见缩写 Savage。
- **绝 / 绝本**：究极之战，英文常见缩写 Ultimate。
- **高难**：通常泛指极、零式、绝等较高难度战斗；发招募时最好写出具体副本和目标。
- **开荒**：队伍第一次学习或推进副本机制。招募可能分为看机制、到某阶段、过本等目标。
- **进度队**：从约定的机制阶段继续练习；加入前要确认自己是否达到该阶段。
- **练习队 / 练习**：以熟悉机制或练习特定阶段为主，不一定要求快速通关。
- **伐木 / farm / 周回**：重复通关以收集坐骑、装备、兑换物或熟练度。招募通常会写明目标。
- **观光**：低压力体验副本、音乐或场景，通常不以高效率通关为首要目标。
- **狂暴**：首领到达时间限制后发动强制团灭攻击；“见狂暴”常指队伍已打到该时间点。
- **渡劫**：口语，指反复尝试后终于通过副本或阶段；不同玩家使用习惯略有差异。
- **解限**：使用解除等级或人数限制的方式进入旧副本，常用于旧内容刷坐骑或物品。

## 战斗机制口语

- **点名**：机制选中一名或几名玩家。需要看提示判断应集合、分散、远离队伍还是引导到指定位置。
- **分摊**：多人站在同一范围共同分担伤害；独自承受可能会倒地。
- **分散**：被点名的玩家彼此拉开，避免范围重叠伤害队友。
- **死刑**：对单名玩家或坦克造成很高伤害的攻击。通常需要减伤、换坦或治疗准备，具体看副本。
- **击退**：把玩家推离目标或中心。可用击退无效技能、靠近击退源或站到安全位置处理，按机制决定。
- **塔**：需要玩家站入的地面圆形区域；通常需要按要求分配人数，漏踩可能导致额外伤害或团灭。
- **分组 / 分位**：按队伍宏把成员分配到点位或小组。H1/H2、D1-D4 只是位置编号，读宏后确认自己的位置。
- **狂暴线**：队伍必须在时间限制前打完的输出要求。出现“压阶段”时，指希望在首领进入后续机制前打到某个阶段。

## 日常与组队交流

- **日随**：随机任务的日常简称。
- **野队**：通过随机匹配或招募临时组成的队伍。
- **固定队**：由一批玩家长期约定时间一起打本的队伍。
- **亲友队**：朋友或熟人组成的队伍，目标可能是体验、练习或通关。
- **豆芽**：头顶带新手标志的玩家，社区也常用来泛指新玩家；不等于对操作水平的判断。
- **导师**：完成游戏内导师条件的玩家称号。称号不保证对某个副本或职业都熟悉。
- **缺 1 / 7=1**：队伍还缺一名成员；“7=1T”通常表示已有七人、还需要一名坦克，具体以招募内容为准。
- **锁位 / 锁职业**：某个位置或职业已被预留。加入前确认是否还能报名该位置。
- **一需**：招募中的掉落分配约定，通常表示每人进队前报一个优先需求物品。坐骑、箱子和职业限制可能另有规则，入本前确认。
- **低保**：高难副本奖励的口语简称，具体指代可能是周奖励、兑换物或保底奖励；先确认当前讨论的副本和版本。

## 特殊地图简称

- **BZY / BZJ**：博兹雅相关内容，通常指南方博兹雅战线，也可能泛指女王之刃任务线。
- **高原**：扎杜诺尔高原，博兹雅后续的特殊区域。
- **SM**：部分玩家把博兹雅区域中的冲突战称为 SM。
- **CE**：Critical Engagement 的缩写，对应紧急遭遇战。
- **GC**：部分博兹雅攻略或招募中指帝国湖岸堡攻城战。
- **QJ**：部分玩家对旗舰达尔里阿达号攻略战使用的简称。
- **新月岛 / 南征 / 北征**：蜃景幻界新月岛及其南征之章、北征之章。问“岛里怎么升级”时，通常要区分角色等级与岛内知见等级。
- **辅助职业**：新月岛玩法中的附加职业，使用范围限于岛内相关规则；不要和常规战斗职业混为一谈。

特殊地图缩写常来自旧攻略或固定队习惯；SM、GC、QJ 等简称在其他语境也可能有别的意思。先结合上下文确认。

## 回答时的处理方式

1. 群聊只写简称时，优先把简称展开成正式内容名，再回答。
2. 站位和机制处理以当前队伍宏、当前副本版本为准，不要仅凭 H1、D3 等编号推断具体站哪。
3. “低保”“一需”“狂暴”等词可能随副本和招募规则改变含义；解释时补上适用场景。
4. 词表没有收录或上下文不明时，直接追问简称指什么，不要编造展开方式。
