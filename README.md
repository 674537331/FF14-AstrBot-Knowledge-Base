# 最终幻想XIV（FF14）中文知识库

面向 AstrBot 原生知识库整理的 FF14 国服简体中文资料。知识条目按主题分类；较大的文件拆成约 550 KB 的 Markdown 分卷，便于上传和向量化。

## 内容目录

- 知识库/职业与战斗技能/：职业和战斗技能。
- 知识库/状态效果/：状态、增益和减益效果。
- 知识库/物品与装备/：物品名称、分类、等级和游戏内说明，共 15 卷。
- 知识库/副本与战斗内容/：副本和战斗内容。
- 知识库/任务与剧情文本/：任务和剧情基础资料。
- 知识库/任务与剧情文本（可选）/：更完整的任务目标和剧情文本，共 66 卷，含剧透，按需导入。
- 知识库/地图区域与交通/：地图、区域和交通信息。
- 知识库/制作采集与钓鱼/：配方、采集和钓鱼资料，共 7 卷。
- 知识库/成就坐骑与表情/：成就、坐骑和表情，共 2 卷。
- 知识库/NPC怪物与FATE/：NPC、怪物和 FATE 资料，共 6 卷。
- 知识库/知识范围与回答规则/：知识范围和回答边界。

在 AstrBot 中按主题上传相应目录的所有 .md 文件。建议先导入核心游戏资料，完整剧情文本可按需追加；同一目录中的分卷应全部上传。

## 数据来源与范围

资料从国服简体中文（CHS）数据整理，来源项目：[InfSein/ffxiv-datamining-mixed](https://github.com/InfSein/ffxiv-datamining-mixed)。数据来自本地解包快照，仓库内容不会自动随游戏版本更新；市场价格、当前版本配装、活动日程等实时信息不在范围内。
