# 最终幻想XIV（FF14）中文知识库

面向 AstrBot 原生知识库整理的 FF14 国服简体中文资料。文件按约 600 KB 的小卷拆分，便于上传和向量化；条目文本与顺序保留。

## 内容

- `知识库/物品与装备/`：物品名称、分类、等级和游戏内说明，共 15 卷，原始记录 51,225 条。
- `知识库/任务与剧情文本（可选）/`：任务目标与剧情文本摘录，共 66 卷，原始文本记录 251,213 条；含剧透，按需导入。

在 AstrBot 中上传相应目录的所有 `.md` 文件。建议先导入物品资料，任务剧情按需追加；不要重复上传旧的大文件。

## 数据来源与范围

资料从国服简体中文（CHS）数据整理，来源项目：[InfSein/ffxiv-datamining-mixed](https://github.com/InfSein/ffxiv-datamining-mixed)。数据来自本地解包快照，仓库内容不会自动随游戏版本更新；物品价格、当前版本配装、活动日程等实时信息不在范围内。
