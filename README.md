# 最终幻想XIV（FF14）中文知识库

面向 AstrBot 原生知识库整理的 FF14 国服简体中文资料。内容按较小的 Markdown 分卷，便于逐批上传和向量化。

## 内容

- `知识库/物品与装备/`：物品名称、分类、等级和游戏内说明，共 5 卷。
- `知识库/任务与剧情文本（可选）/`：任务目标与剧情文本摘录，共 22 卷，含剧透；按需导入。

每个分卷都保持完整条目或任务分组。上传时选择对应目录内的 `.md` 文件；不要把 ZIP 上传到 AstrBot，也不要同时上传此前的整份大文件，以免重复索引。建议先导入物品与装备资料，再视需要导入任务剧情资料。

## 数据来源与范围

资料从国服简体中文（CHS）数据整理，来源项目：[InfSein/ffxiv-datamining-mixed](https://github.com/InfSein/ffxiv-datamining-mixed)。数据来自一个本地解包快照，仓库内容不会自动随游戏版本更新；物品价格、当前版本配装、活动日程等实时信息不在范围内。

上游仓库根目录未发现单独的 LICENSE 文件。本仓库不声明拥有《最终幻想XIV》游戏文本、名称或其他游戏资产的版权，也未为这些内容另行授予许可。请查阅上游项目及游戏权利方的相关规则后再公开再分发。
